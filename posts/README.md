`public/blog/<slug>/index.html` তৈরি হয়ে যায়, ওয়েবসাইট আর অ্যাপ দুটোতেই দেখা যায়।

ফাইলের নামই URL হয় — `bad-nazar-theke-bachar-amal.md` → `/blog/bad-nazar-theke-bachar-amal/`

## প্রকাশ

- `draft: true` দিলে পোস্টটা তৈরি হবে না — পরে `false` করলে প্রকাশ হবে।
- সব লেখা তারিখ অনুযায়ী নতুন থেকে পুরনো ক্রমে সাজানো থাকে।
- `node build.js` → Vercel-এ push করলেই লাইভ।

## ফেসবুক ড্রাফট থেকে আসা পোস্ট

`fb-ruqyah-content/drafts/`-এর কার্ডগুলো থেকে ২৫৭টি পোস্ট এখানে আছে, সবই
**`draft: true`** অবস্থায়। কারণ ব্লগ ফেসবুকের পেছনে থাকা দরকার — যে লেখাটা
ফেসবুকে "সোয়াইপ করে দেখুন" বলে টিজার দিচ্ছে, সেটার উত্তর ব্লগে আগেই থাকলে
টিজারের জোর থাকে না।

**নিয়ম: ফেসবুকে পোস্ট যাওয়ার পর সেটা ব্লগে ছাড়ুন।**

```bash
python tools/publish_posts.py --list                    # কোনটা লাইভ, কোনটা বাকি
python tools/publish_posts.py day-01-post-1             # একটা ছাড়ুন
python tools/publish_posts.py --series ruqyah-program --upto 20   # পর্ব ১–২০
python tools/publish_posts.py --from-posted             # posted/ ফোল্ডারে যা আছে সব
python tools/publish_posts.py --unpublish day-01-post-1 # ভুল হলে ফেরত
node build.js                                            # তারপর বিল্ড ও ডিপ্লয়
```

নতুন ড্রাফট এলে `python tools/import_fb_drafts.py --covers` — এটা আগে ছাড়া
পোস্টগুলোকে আবার লুকিয়ে ফেলবে না, `draft` অবস্থা যেমন ছিল তেমনই থাকবে।
