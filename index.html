⚠️ এটি কোনো রোগ নির্ণয় নয়। এখানে শুধু আপনার জানানো লক্ষণ অনুযায়ী রুকইয়াহর আমল সাজিয়ে দেওয়া হয়। শারীরিক বা মানসিক অসুস্থতায় অবশ্যই যোগ্য চিকিৎসকের পরামর্শ নিন।
⚠️ এটি একটি আমলের রুটিন — কোনো চিকিৎসা প্রোটোকল নয়। চলমান কোনো চিকিৎসা বা ওষুধ এর জন্য বন্ধ করবেন না।

⚙️ এআই চ্যাট সেটিংস

ডিফল্টভাবে, চ্যাটবটটি আমাদের ফ্রী প্রক্সি সার্ভার ব্যবহার করবে। আপনি যদি আপনার নিজস্ব ফ্রি Gemini API Key ব্যবহার করতে চান, তবে নিচে কি-টি ইনপুট দিতে পারেন (এটি আপনার ব্রাউজারে সুরক্ষিত থাকবে):

* আপনার নিজস্ব API Key তৈরি করতে Google AI Studio-তে যান এবং বিনামূল্যে একটি তৈরি করুন।
