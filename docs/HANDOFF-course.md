## পরের কাজ (অগ্রাধিকার অনুসারে)

1. **ভিডিও তিনটে Unlisted কিনা নিশ্চিত করা।** Public থাকলে চ্যানেলে গিয়ে যে কেউ
   দেখে ফেলবে আর পুরো গেটটাই অর্থহীন। ব্যবহারকারীকে জিজ্ঞেস করো — YouTube Studio
   থেকে দেখতে হয়, কোড থেকে বোঝার উপায় নেই।
2. **তিনটে নোট PDF এখনো নেই** (টেলিগ্রামের এক্সপোর্টে ফাইল আসেনি, ডিস্কেও পাইনি):
   - `সেশন_১_স্বপ্নের_ব্যাখ্যা_ও_লিখিত_জাদুর_রুকইয়াহ.pdf`
   - `Day-5-Monthly-Session-Tabia-Ruqyah.pdf`
   - `Day-9-Monthly-Session-Ashiq-Jinn-O-Santan.pdf` ← n=9-এর ভিডিও আছে, নোট নেই
   পেলে: `node tools/make_course_notes.js --course course-live --lesson <n> --from <pdf>`
3. **দিন ১–৮-এর রেকর্ডিং YouTube-এ নেই** — টেলিগ্রামে m4a/ogg অডিও হিসেবে আছে
   (`Day 1 part 1.m4a`, `Recording (10)…(16).m4a`, একটা ৬২ মিনিটের video_file)।
   ব্যবহারকারী সিদ্ধান্ত নিয়েছেন: **এখন শুধু তিনটে ভিডিও-সেশনই থাকবে**। পরে
   অডিওগুলো unlisted ভিডিও হিসেবে আপলোড করলে শুধু লিংক বসালেই হবে।
4. **সেশনের নম্বর ব্যবহারকারীর নিজের লেবেলেই গোলমেলে** — আশিক জিন ও রিজিক দুটোকেই
   তিনি কোথাও "৯" বলেছেন (`Day-9` PDF vs "session ৯" মেসেজ vs `Day-10` PDF)।
   **তারিখ ধরে ৯/১০/১১** বসানো হয়েছে। তিনি বদলাতে বললে `catalog.json`-এর `n` আর
   `private.json`-এর কী দুটোই একসাথে বদলাতে হবে (progress-এর কী ওই `n`)।

## নিয়ম যেগুলো ভাঙলে নীরবে ভাঙবে

1. **ডিপ্লয় = ওয়ার্কিং কপি থেকে `vercel --prod`। `git push` নয়।**
   `course_data/private.json` ও `course_notes/` gitignored, প্রোডাকশনে যায়
   `vercel.json`-এর `includeFiles` দিয়ে। git-ডিপ্লয়ের সোর্স রিপো নিজেই, তাই push
   করলে ফাংশন খালি হাতে যায় আর প্রতিটা নোটে `404 not_found` — বিল্ড লগে কিছুই
   থাকে না। শেখার শিল্পের সাথে ঠিক এটাই হয়েছিল।
2. **`.vercelignore`-এ `course_data/` বা `course_notes/` যোগ করা নিষেধ** (ওখানে
   কমেন্টে কারণ লেখা আছে; `book_notes/`-এর মতো দেখতে বলে ভুল হওয়ার ঝুঁকি আছে)।
3. **প্রতি ডিপ্লয়ের আগে `node tools/check_course_data.js`** — non-zero exit মানে
   ডিপ্লয় করা যাবে না। `npm run check`-এ এটা নেই (ওটা কোডের পরীক্ষা, এটা কনটেন্টের)।
4. **কোর্সের সব কোড `#web-only` মার্কারের ভেতরে** — `tools/audit-native.js` APK-তে
   দাম/কেনার কিছু লিক করলে বিল্ড ফেল করায়।
5. **নতুন `styles/NN-*.css` = `index.html`-এ নতুন `<link>` একই সাথে**, নইলে
   `build.js` ফেল করে (ইচ্ছাকৃত)।
6. **রিভিউ target-এ শুধু হাইফেন** (`course-live-c9`) — আন্ডারস্কোর দিলে
   `firestore.rules`-এর `<uid>_<target>` ভাগ ভুল জায়গায় হয়ে লেখা আটকে যায়।

## নতুন সেশন যোগ করার ধাপ

```bash
# ১. ইউটিউবে unlisted আপলোড → ID কপি
# ২. course_data/catalog.json — নতুন lesson সারি (আসল শিরোনাম, hasVideo: true)
# ৩. course_data/private.json — সেই n-এর নিচে "video": "<ID>"
# ৪. নোট থাকলে
node tools/make_course_notes.js --course course-live --lesson <n> --from "<file.pdf|.html>"
python tools/watermark_course_notes.py
# ৫. গেট
node tools/check_course_data.js
# ৬. ডিপ্লয়
vercel --prod
```

৪ নম্বর ধাপ নিজেই `private.json`-এ নোটের পথ আর `catalog.json`-এ `hasNotes` বসায়।

কোনো স্ক্রিপ্ট ধরে না, ছাত্র প্রথম দিনেই ধরে।

## যেসব ফাঁদে ইতিমধ্যে পড়া হয়েছে (আবার পোড়ো না)

- **jsdom-এ `app.js`-এর `let`/`const` আলাদা eval থেকে ছোঁয়া যায় না** (function
  ঘোষণা যায়, কারণ ওগুলো window-এ বসে)। `tools/smoke-course.js` তাই টেস্ট-হুকটা
  একই সোর্সের শেষে জুড়ে eval করে।
- **`/Type /Page` গুনে PDF-এর পাতা গোনা যায় না** — আধুনিক PDF অবজেক্ট `/ObjStm`
  কম্প্রেসড স্ট্রিমে রাখে, তাই ১৩ পাতার ফাইলও "০ পাতা" দেখাত। এখন PyMuPDF।
- **`.a4-page`-এ `min-height` থাকলে ছাপায় উপচে পড়ে** — ৬ পাতার হ্যান্ডআউট ১১ পাতা
  হয়। লেখা হারায় না, তাই এটা warning; পাতা *কমে* গেলে error।
- **নোটের iframe-এ `allow-scripts` নেই** (ইচ্ছাকৃত), তাই ডকুমেন্টের নিজের
  "প্রিন্ট"/"PNG" বোতাম কাজ করে না — `make_course_notes.js` ওগুলো CSS দিয়ে লুকায়।
- **`ruqyah-course` প্রজেক্টের হ্যান্ডআউটে `**bold**` মার্কার টেক্সট হয়ে ছাপা হয়**
  — ওই প্রজেক্টের বাগ, এখানকার নয়, কিন্তু ওই হ্যান্ডআউট নোট হিসেবে দিলে চোখে পড়বে।
- **`createYTPlayer()` ছোঁয়া নিষেধ** — ওটা অডিও লাইব্রেরির `currentPlayerItem` ও
  autoplay-next-এর সাথে জোড়া। কোর্সের প্লেয়ার আলাদা: `createCourseYTPlayer()`।
- **অগ্রগতি Firestore-এ থ্রটলড ৩০ সে.** — নইলে `watchUnlocks`-এর onSnapshot
  মিনিটে ১২ বার গোটা হোম স্ক্রিন আঁকত।

## পরীক্ষা করার সময় যা মনে রাখতে হবে

গেটটা আসল: **নিজের অ্যাকাউন্টে সদস্যপদ চালু না থাকলে রাকী নিজেও কোর্স দেখতে পাবেন
না।** অ্যাডমিন প্যানেল (🩺 FAB → 💳 Purchases) থেকে নিজেকে ৩০ দিনের মেম্বারশিপ
দিয়ে পরীক্ষা করতে হয় — `users/<uid>.memberships['live-class'].until` শুধু
অ্যাডমিনই লিখতে পারে (`firestore.rules`)।
