# মাসিক লাইভ রুকইয়াহ কোর্স (৳৪৯০)

আগে এটি কেবল মেসেঞ্জারে বিক্রি হত: কেউ `Session` লিখতেন → অটো-রিপ্লাই → ফর্ম →
পেমেন্ট → হাতে করে গ্রুপে যোগ। প্রতিটা ধাপে মানুষ হারাত, আর সবচেয়ে বেশি হারাত
রাতে, যখন উত্তর দেওয়ার কেউ থাকত না। এখন সাইট থেকেই যুক্ত হওয়া যায়।

## অন্য পণ্য থেকে আলাদা কোথায়

| | বই ও ডায়াগনোসিস | লাইভ কোর্স |
|---|---|---|
| অ্যাক্সেস | `users/<uid>.courses` অ্যারে — **চিরস্থায়ী** | `users/<uid>.memberships['live-class'].until` — **৩০ দিন** |
| আনলক | বই সাথে সাথে, কোর্স অ্যাডমিন Confirm করলে | অ্যাডমিন Confirm করলে |
| নবায়ন | নেই | প্রতি মাসে, মেয়াদ **যোগ হয়** |

`courses` অ্যারেতে মেয়াদ রাখার জায়গা নেই — ওখানে থাকা মানেই চিরকাল থাকা। তাই
সদস্যপদ আলাদা ফিল্ডে, আর `ownedIds()` সেটাকে মালিকানা হিসেবে গোনে না। যা গোনে
সেটা `hasProduct(id)` — মেয়াদ শেষ হলে কার্ড আবার নবায়নের প্রস্তাব দেখায়।

নবায়নের হিসাব `extendMembership()`-এ: **আজ আর বর্তমান মেয়াদ — যেটা পরে, সেখান
থেকে ৩০ দিন**। কেউ এক সপ্তাহ আগে নবায়ন করলে সেই সপ্তাহটা হারান না। উল্টোটা
করলে মানুষ শিখে যেত যে দেরিতে নবায়ন করাই লাভজনক।

## টেলিগ্রাম লিংক — কোডে বা গিটে কখনো নয়

তিনটি প্রাইভেট ইনভাইট লিংক (সেশন চ্যানেল, বোনদের গ্রুপ, ভাইদের গ্রুপ) আছে
**কেবল একটি Vercel এনভায়রনমেন্ট ভেরিয়েবলে**:

```
TELEGRAM_LINKS = {"session":"https://t.me/+…","sisters":"https://t.me/+…","brothers":"https://t.me/+…"}
```

```bash
vercel env add TELEGRAM_LINKS production      # preview ও development-এও
```

**কেন:** `app.js` একটা পাবলিক স্ট্যাটিক ফাইল — যে কেউ
`alquranicruqyahhealing.com/app.js` খুলে পড়তে পারে; আর রিপোও পাবলিক। এই দুই
জায়গার যেকোনোটিতে লিংক রাখা মানে টাকা নেওয়া গ্রুপের দরজা খুলে রাখা। একবার
বেরিয়ে গেলে ফেরানোর উপায় নেই — লিংক বাতিল করে সব সদস্যকে আবার ইনভাইট করতে হবে।

তাই `/api/membership` টোকেন যাচাই করে, Firestore থেকে মেয়াদ পড়ে, তারপর তবেই
লিংক ফেরত দেয় — `api/book.js` যেভাবে বইয়ের পাতা দেয়, ঠিক সেভাবে। এনভায়রনমেন্ট
ভেরিয়েবল সেট করা না থাকলে এন্ডপয়েন্ট 501 বলে আর কার্ডে লেখা থাকে যে লিংক এখনো
যুক্ত হয়নি — খালি বাক্স দেখায় না।

**যাচাই** (ডিপ্লয়ের পর যেকোনো সময়):

```bash
git grep 't\.me/+'                        # → কিছুই না
grep -c 't\.me' public/app.js             # → 0
curl -s https://alquranicruqyahhealing.com/api/membership   # → 401
```

## টাকা ফেরতের গ্যারান্টি

সাইটে লেখা আছে: **প্রথম ৩টি লাইভ সেশনে অংশ নেওয়ার পরও** কাজে না লাগলে,
**চলতি মাস শেষ হওয়ার আগে** জানালে পুরো হাদিয়া ফেরত।

শর্ত দুটো ইচ্ছাকৃতভাবে স্পষ্ট করে লেখা, কারণ এটি লিখিত প্রতিশ্রুতি। সাথে এটাও
লেখা যে **আরোগ্যের নিশ্চয়তা নয়** — শিফা আল্লাহর হাতে, তাই "না সারলে টাকা ফেরত"
ধরনের শর্তে কোনো চুক্তি হয় না। গ্যারান্টিটি কেবল কোর্সটি উপযোগী কি না তা নিয়ে।

ফেরত দিলে অ্যাডমিন প্যানেলে ওই purchase-এ **❌ Reject** চাপুন — সদস্যপদের মেয়াদ
তখনই শূন্য হয়ে যাবে।

## যা এখনো সাইটে লেখা হয়নি

ফেসবুকে বলা কিছু কথা যাচাই করা যায়নি, তাই বসানো হয়নি: **"৮০+ সদস্য"**,
**"প্রতি সেশনে ৩০ মিনিট তাফসীর"**, **"পূর্ণ PDF নোট"** (কপি-ফাইলে আছে শুধু
`সেশন নোট`)। সংখ্যা আন্দাজে লেখা এই প্রজেক্টের নিয়মবিরুদ্ধ। নিশ্চিত হলে
`app.js`-এর `COURSES` ও `landing.html`-এর `#live-class` — দুই জায়গায় যোগ করতে হবে।

সেশন সংখ্যা **"কমপক্ষে ১২টি"** লেখা আছে (ব্যবহারকারীর সিদ্ধান্ত): মাসে সংখ্যা
কমবেশি হলেও প্রতিশ্রুতি ভাঙে না। `fb-ruqyah-content/drafts/cta_course.py`-তে
লেখা আছে "১২টি" — ফেসবুকের কপি বদলালে সেখানেও বদলাতে হবে।
